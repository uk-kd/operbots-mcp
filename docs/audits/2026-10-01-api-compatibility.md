# Совместимость MCP с API панели

Проверено 1 октября 2026 года: MCP 0.2.0 и панель operbots после исправлений
аудита, коммит `951e95d`. HTTP-контракт совместим; переноса маршрутов или
изменения аргументов инструментов не требуется. Исправлены сообщения MCP,
которые неверно описывали состояние сценария или последствия операции.

OpenAPI панели до исправлений (`fba1de4`) и после них содержит одинаковые
148 путей, 203 операции и 200 схем. Сравнены целиком разделы `paths` и
`components.schemas`; различий нет. Изменённые проверки доступа и восстановление
архива дополнительно проверены через MCP, HTTP и отдельную PostgreSQL 18 с pgvector.

Исправления MCP:

- `market_install` сообщает фактический `is_active` из ответа. Первый сценарий
  своего вида автоматически включается только с `flow.publish`; это правило
  отражено также в описаниях `flows_save` без `copy_of`, `flows_import` и README.
  Копирование оставляет сценарий черновиком.
- `flows_publish` объясняет, что выключаются остальные сценарии того же вида.
  Сценарии диалогов и сообщества могут оставаться активными одновременно.
- `flows_delete` предупреждает об удалении собственной публикации в маркете.
  Установленные у других ботов копии сохраняются.
- `members_list` объясняет отсутствие ссылки приглашения без `member.invite`.
  Метаданные приглашения остаются видимыми, скрытые token и URL не раскрываются.
- `bots_save` описывает восстановление архивной записи. Проверено сохранение UUID,
  настроек, статистики, сценариев и диалогов при повторном подключении.

Проверки прошли:

- `npm test`: 121 тест MCP и 5 проверок собранных плагинов Codex и Claude Code.
- `npm run typecheck`: ошибок нет.
- `npm run test:backend`: 75 проверок с владельцем, ограниченным участником
  и режимом только чтения. В том числе запрещены снятие отзыва чужого права
  `flow.publish` и публикация без этого права; создание, импорт и установка
  остаются черновиками. Смена пароля завершает браузерные сессии, API-ключ работает.

Реальные боты и внешние сервисы не запускались. В QA подменена только проверка
токена Telegram; восстановление записи и проверки прав выполняет настоящий backend.
Данные, пользователи и токены тестовые, база отдельная. Непосредственное взаимодействие
с Telegram, MAX и ИИ-провайдерами этим прогоном не проверяется.
