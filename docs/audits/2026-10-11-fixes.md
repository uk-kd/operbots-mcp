# Исправления аудита MCP

Ветка: `audit/panel-nodes-mobile-mcp-2026-10-11`. Коммиты кода: `c74cec2`, `f23c605`.

- `invites_revoke.invite_id` проверяется UUID-схемой до HTTP.
- Общий выбор сценария использует `pickByName`, отклоняет пустой/неоднозначный hint. Отсутствующий UUID возвращает 404 и не выбирает другой сценарий с таким именем. Пустой `copy_of` не создаёт новый сценарий.
- `flows_save` требует ожидаемую `version` для изменения существующего графа и передаёт версию вызывающего клиента без подмены свежей. Metadata-only и правка новой копии используют только что полученную редакцию. Описание можно очистить явным null. Контракт описан в README.
- Скачивание записывает тело чанками, с пределом 100 МиБ, общим timeout/error contract и эксклюзивным созданием файла. При ошибке удаляется только свой незавершённый файл; существующий файл сохраняется.
- Собранный plugin bundle обновлён вместе с исходниками. Новых зависимостей нет.
